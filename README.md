## 认识知芽

知芽是一款开源 AI 教学应用，面向小学至高中阶段的编程与人工智能教育。

学生可以通过对话学习，在同一个课堂里看讲解、做练习、运行代码。教师可以用它准备教案和教学材料，再分享给班级。

## 支持的特性

- **学习档案**：通过对话了解学习基础、目标与偏好，为后续教学提供参考。
- **互动课堂**：结合图文课件、教学插图、动画和 B 站视频讲解。课程按章节组织，可以随时提问、继续学习。
- **随堂练习**：支持单选、多选、判断和填空题，提交后由 AI 讲解反馈。
- **编程实践**：在课堂中编辑和运行代码，支持 Python、JavaScript、TypeScript、C、C++、Java、Go 和 Rust。
- **教学资料**：上传文本、PDF、Word、PPT 和图片作为课堂材料。接入知识库后，可检索教材与教学资料，并在对话中查看引用。
- **语音交流**：支持语音输入、连续语音对话和朗读回复。
- **备课与导出**：通过对话生成、修改教案和课件，导出为 PPTX、Word 或 HTML。
- **班级分享**：创建或加入班级，通过链接分享教学内容，选择仅自己、指定班级或公开访问。
