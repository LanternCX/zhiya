# Python 入门学习资料

本资料用于知芽学生版演示，内容为人工编写的基础知识样例。

## 变量与输出

Python 中，赋值语句把名字绑定到一个对象。写下 `baozi_price = 2` 后，可以用 `baozi_price` 再次取用这个值。这条赋值语句本身不会在屏幕显示数字。

调用 `print(baozi_price)` 可以把当前值显示到输出中。把赋值改成 `baozi_price = 3`，再执行同样的输出语句，会看到 3。

## 输入

`input()` 接收用户输入，返回字符串。`name = input("你叫什么名字？")` 把返回的字符串绑定到 `name`。
